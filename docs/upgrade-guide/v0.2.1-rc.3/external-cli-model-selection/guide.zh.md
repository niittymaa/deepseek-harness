# 外部 CLI 模型选择

[English](guide.md) | 中文

## 变更

配置的外部 CLI 路由在聊天模型选择器中提供实际模型标识符。未知模型标识符会被拒绝，不会使用可执行程序的默认模型。重复或空模型标识符、与提供商路由相同的模型标识符以及空推理声明会被拒绝。显式模型选择会拒绝基础 CLI 参数中冲突的模型和推理强度设置。

## 迁移

1. 在模型设置中编辑每个本地 CLI 提供商，添加希望选择的模型标识符。Agy 可以获取模型目录；其他提供商使用配置的模型列表。
2. 为每个模型声明支持的推理级别。在聊天中选择模型时，从基础 `args` 中删除 `--model`、`--effort`、`--reasoning-effort` 和 Codex 模型配置覆盖项。
3. 对于自定义可执行程序，选择其 CLI 类型，或提供含 `{model}` 和 `{effort}` 占位符的 `modelArgs` 和 `effortArgs` 数组。
4. 在聊天输入框下方选择模型和推理级别并发送消息。选择提供商的 CLI 默认项可保留其自身的模型和推理配置。没有模型声明的现有配置保留此默认项。
